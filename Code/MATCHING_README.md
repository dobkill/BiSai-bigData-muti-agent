# 三源配对流水线

在项目根目录运行：

```powershell
python -X utf8 Code/match_day.py --input Datas/数据/2025.5.1 --output Datas/匹配数据
```

依赖：Python 3.10+、requests、pydantic 2、numpy、openpyxl；Ollama模型 `qwen3.5:9b-q8_0` 和 `bge-m3`。本次使用已有Conda基础环境，不改变系统包。

在新环境中可用 `python -m pip install -r Code/requirements.txt` 安装Python依赖，并用 `ollama pull bge-m3` 准备嵌入模型。文本模型名可通过 `--model` 指定，服务地址可通过 `--ollama-url` 指定。

每篇新闻一个主组，最多一篇舆论，新闻每个平台最多一个雷达候选活动。模型独立抽取新闻/舆论，程序校验原文引用、显式数量和活动时刻；型号/时段/地点关系召回与BGE-M3向量召回取并集，关联Agent确认候选，精确最大权分配避免抢占。缺源组允许一次扩大召回。核验Agent逐字段比较事实，程序强制执行来源独立性、证据精度、国籍/数量反证、雷达异常和归属歧义检查。

GPT复核后增加原文任务动词和进出动词校验，排除把平台用途当任务、把机动当进入的抽取错误。公共事实采用明示值矩阵复查，单独核验时间起止端点、任务和地点反证；保留模型原提议。近分候选按强制替换后的整个分配损失评估，在一对一假设下说明竞争是否已消解，不能用全局分数消解事实冲突。

全局分配后，缺舆论的新闻与剩余同型号舆论再进行一次反证复核，防止模型把受污染字段误当成不同事件；保留判定记录，不强制补齐。核验输出限制实际平台数与来源ID，防止模型产生无效或重复字段。地点可降到两类来源实际共同支持的区域；未证实的具体地点单独保留，已存在的明确冲突不能通过扩大范围消解。

扩大复查从当天全量索引取分数，优先保留同身份候选，单次送入模型的候选受上下文预算限制，较大集合使用简要字段。舆论ID与雷达ID分别约束，平台索引与输出数量在schema和程序中双重检查。失败重试只保留原始输入及校验错误，不追加失败长回答。仅输出schema收窄且输入、模型、指令完全相同时，旧缓存经过当前完整校验后可以迁移；改变语义指令或输入仍须重新推理。

待复核关联保留实际匹配的平台索引，不能把未确认事件归属误当成平台字段缺失。模型的未消解问题作为原提议保存，再与已校验事实矩阵对照：原文反证继续阻断，已获两类支持的事实不因某一来源缺字段重复阻断；未知归属疑点仍保留。不同具名地点即使同属“其他”方向也不视为相同地点。

若地点反证导致模型拒绝关联，但同日在双方文本全集中，型号/国籍/明确任务组合各自唯一，新闻与已关联雷达的具体时段又吻合，程序允许保留为 `uncertain` 待复核配对（启发式关联分数0.65，非校准概率），同时保存原模型拒绝意见。此候选必归不可信，不能冒充已确认同一事件；出现同身份的其他活动、明确时间不符、缺具体雷达时段时不触发。

规则位于 `event_matcher/geography.py`，来自用户PDF第2页。方向归属不等于具体区域等价。飞机坐标只提供用于召回和活动选择的宽泛方向候选；缺乏官方区域边界时不充当精确海域真值。同批号不同起始位置簇形成独立候选，批号不视为唯一目标身份。仅已关联的候选进入核验，其余分支在候选记录及未匹配材料中完整保留；跨目标的位置距离不自动成为事件反证。

活动时间区分文本报道覆盖、雷达观测覆盖和明确开始/结束断言。包含区间可印证共同覆盖部分，首末观测点不当作完整活动起止；明确边界矛盾及不重叠区间仍保留冲突。任务核验区分远海训练环境与具体训练科目，只确认共同支持的训练事实；未获两类支持的具体科目单独列为待核实，明确不同任务不得以多数票消解。

输出位于 `Datas/匹配数据/日期/`：浏览页、Excel/CSV总表、可信/不可信分组、未匹配材料、完整性检查、模型原始响应与缓存、SQLite证据和向量索引。每组保留原始文本字节，雷达保留全部原始列及Excel行号。重复运行复用有效模型缓存，原有分组移入历史目录，不删除原始数据。

`manifest.json` 记录Git提交及实际代码SHA-256；历史导出保留当时总表和分类。GPT逐组审查见日期目录的 `审查记录/`，修复过程见 [迭代记录](docs/iteration_review.md)。

`--stage extract` 仅完成文本抽取，供检查或断点恢复。模型失败会停止并保留缓存；不会伪装成规则回退已完成。

验证：

```powershell
python -X utf8 Code/test_matching.py
```

模型分类没有官方真值准确率；不可信包括缺源、归属歧义、异常与冲突。日报标记单独按核心海域检查，本程序不生成官方提交日报。
