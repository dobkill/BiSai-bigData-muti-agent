## 分组依据

- **可信事件**：三类来源完成同一事件关联，关键事实至少两类来源相互支持，第三类来源未给出明确冲突值。
- **不可信事件**：除可信事件外的全部材料，包括明确冲突、配对歧义、证据不足、缺少来源及未配对记录；保留具体原因。
- **雷达依据**：雷达记录作为时空、数量和轨迹核验依据之一，不作为无条件优先真值；任一来源的明确冲突都不能被多数票抵消。
- **归属**：每篇新闻一个主组，舆论一一对应；各平台各有一个雷达批次槽位。全局比较合理组合，不因先配对就从候选计算中永久删除材料。
- **地点入库**：原文与引文保留，标准区域、PDF方向在进入SQLite证据库前完成归一化；检索当前日期的全量结构化证据。
- **身份**：型号、舰级、舰名、舷号分别处理。身份字段冲突可以保留对应候选，事实核验不得用其他字段或多数票抵消冲突。
- **时间**：比较正文活动区间，发布时间不参与。重叠、包含或接壤可提供对应线索；默认接壤容差 15 分钟，相隔不超过 3 小时只保留候选。只有同一天不足以确认同一活动。
- **区域与歧义**：具体区域相同或包含可相容；同方向不等于同事件。禁用所选对应后若仍有近似等效的整体方案，保留待确认状态。
- **缺失与多平台**：证据不足不强配最后剩余材料。多平台正文在组内按平台核验，不增加主组数量，也不分配编队总数。
- **模型审查与重算**：启用模型时审查歧义对应，要求两篇真实原文引用；模型偏好不能单独使等效方案成为确认关联。重跑允许重新分配，SQLite保存历次结果和变更依据。
- **数量、任务**：用于事实核验；存在差异时保留疑似关联供人工阅读，禁止直接进入日报。

## 怎样人工阅读

1. 用 `索引.csv` 筛选平台、国家、状态等，进入“分组目录”。
2. 先读每组 **`README.md`**：简短列出对应依据、缺失信息和待确认原因。
3. 并排阅读 `新闻.txt`、`舆论.txt`、`雷达.xlsx`；完整字段和原始位置见 `关联说明.md`。
4. 在 `人工复核.csv` 记录关联是否正确、事实是否可信和修正意见。重新导出保留人工意见，意见暂不自动改变算法结果。

文本按原始字节复制；雷达子表保留全部对应批次的原始字段及 Excel 行号。每组的 `对应候选.csv` 保存备选；每天的 `未归属材料.csv` 保存额外未归属材料清单，未配对材料的原文、雷达副本和理由保存在“不可信事件”目录。额外记录不另计新闻主组。

## 用本地 Ollama 重跑一天

已创建专属 Conda 环境 `multimodal-agent`，本地模型配置为 **`qwen3.5:9b-q8_0`**。打开 Ollama，在项目根目录执行：

```powershell
.\Code\scripts\run.cmd --date 2025-05-01 --single-day --use-llm --strict-llm --max-llm-calls 324 --force --output-dir Code\outputs\one_to_one_20250501_local --review-dir Datas_分组_新版

# 更新效果说明，并逐字节/逐行核对阅读副本；不调用模型
& D:\APP\miniconda\envs\multimodal-agent\python.exe .\Code\scripts\validate_one_to_one.py --analysis-dir Code\outputs\one_to_one_20250501_local --date 2025-05-01 --reference Code\outputs\structure_audit\2025-05-01_新闻舆论雷达对应核对.csv
```

本次重新分组复用此前真实 Ollama 推理的 **100 条抽取缓存**，新增 HTTP 请求 0 次、规则回退 0 次。`--force` 重算关联及核验，但不会清除模型请求缓存。首次无缓存的一天通常需要约 100 次模型请求。

2025-05-01此前已用本地模型完成100篇文本抽取；本次两类分类重算复用其100条模型缓存。147项测试通过，原始材料及50份人工复核表的内容保持一致。`--single-day` 只处理当天，否则默认加载截至当天共7天的历史窗口。多日期结果按日期独立保存；`manifest.json` 记录最近一次运行。

赛题文档在 `Docs/`，原始数据为 80 天。当前 PDF 缺少完整评分细则及官方提交模板，输出仍采用内部格式。验证记录见 [Code/docs/validation.md](Code/docs/validation.md)。
